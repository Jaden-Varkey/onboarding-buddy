🧭 Onboarding Buddy

Chat with any GitHub repo's docs and issues, with every answer cited. Built on Snowflake.

New contributors waste their first week just figuring out how a repo works. Maintainers answer the same setup questions over and over.

View the code on GitHub Built with Snowflake CoCo

What you get

  • Answers with citations from the README, docs, contributing guide and past issues
  • A repo-specific getting-started checklist
  • Good first issues, unassigned ones first
  • Repo health: stars, contributors, issue and PR activity

How it works

  1. Pull docs and closed issues from GitHub into a Snowflake table
  2. Index them with Snowflake Cortex Search
  3. Answer with open-weight Llama 3.3 70B on Cortex AI (AI_COMPLETE)
  4. Compute repo health from the GitHub Archive on the Snowflake Marketplace

Tech stack

  • Snowflake: Cortex Search, Cortex AI, Marketplace, CoCo
  • Open-weight AI: Llama 3.3 70B, Snowflake Arctic Embed
  • Python, Streamlit, GitHub REST API
