**Project Name:** Onboarding Buddy

**Problem Statement:**   
New contributors to open-source projects and student teams lose hours digging through scattered READMEs, docs and old issues just to get set up and understand how the code fits together. Maintainers end up answering the same questions again and again.

**Product MVP:**   
Onboarding Buddy is a chat assistant for any GitHub repository. You paste a repo URL, and it loads the README, docs, contributing guide and closed issues into Snowflake and indexes them with Cortex Search. The interface is a clean chat window with a "Getting started" checklist on the side. Each answer cites the exact file or issue it came from, and it can suggest good first issues for the new contributor to pick up.

Target Users:

* New hires and interns: engineers ramping up on a company's internal repos in their first weeks.  
* Bootcamp and self-taught developers: learners who want to read real codebases but find them overwhelming.  
* First-time open-source contributors: students who don't know where to start in an unfamiliar repo.  
* Hackathon and class project teams: teammates who join late or pick up another team's documented/undocumented code and need to catch up quickly.  
* Open-source maintainers: people who want to stop answering the same setup questions in issues and Discord.  
* Club and research lab members: students taking over documented/undocumented code left behind by graduated members.
